# Design tokens

Every value below is read live from `@/design-system/tokens`, which mirrors
the CSS custom properties defined in `src/styles.css`. This page cannot drift
from the implementation — if a token changes there, it changes here too.

## Colour scales

Semantic tokens are grouped by primitive palette; each group renders as a row
of swatches driven directly by its CSS custom property.

{colorTokenGroups.map((group) => (
  <div key={group.id} style={{ marginBottom: "2rem" }}>
    <h3>{group.title}</h3>
    <p>{group.description}</p>
    <div style={{ display: "flex", flexWrap: "wrap", gap: "0.75rem" }}>
      {group.tokens.map((token) => (
        <div key={token.token} style={{ width: "9rem" }}>
          <div
            style={{
              height: "3rem",
              borderRadius: "var(--radii-sm)",
              border: "1px solid var(--border-subtle)",
              background: `var(${token.token})`,
            }}
          />
          <p style={{ margin: "0.375rem 0 0", fontSize: "0.75rem", fontWeight: 600 }}>{token.label}</p>
          <code style={{ fontSize: "0.7rem" }}>{token.token}</code>
        </div>
      ))}
    </div>
  </div>
))}
