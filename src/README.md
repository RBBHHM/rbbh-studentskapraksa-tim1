# Source projects

- `RBBH.ConnectedParties`: .NET 10 REST API i EF Core SQL Server model.
- `Web`: jedini React frontend, statički SPA za IIS.
- `UnitTests`: procesno-lokalni unit testovi.
- `IntegrationTests`: API i servisni scenariji; koriste podešeni SQL Server kada je dostupan, a testovi koji ga zahtijevaju jasno se označavaju ako okruženje nije spremno.

Kompletne komande i arhitektura su u root `README.md`.
